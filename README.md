# pithpack

Compress codebases into token-lean context bundles for LLMs.

> Pre-release: the design is in [`docs/SDD.md`](docs/SDD.md); vocabulary in [`GLOSSARY.md`](GLOSSARY.md).

## Install

Once released: `cargo install pithpack`.
